# Private selected-profile lookup executor qualification

The private executor implements ordered GSUB single/ligature and GPOS pair format1/2 and mark-to-base over the five pinned Noto selections. It is not a public shaping service or prepared-packet integration. No host shape, metric, classification or raster callbacks are present.

Both substitution and positioning accept only an immutable validated shaping_catalog::View. Every input original GID must occur in its raster directory; the retained companion supplies the exact validated lookup bytes. The trusted generated catalog manifest proves selected MarkCoverage equals admitted GDEF class3 per selection. This is a pinned profile admission fact, not a general OpenType classification algorithm. The generator checks original selected source ValueFormat2==0; runtime additionally scans every selected encoded pair row/cell for nonzero second-value masks before execution.

Input source intervals are nonempty, contiguous, monotone, and either disjoint or identical for canonical expansion groups. Partial overlap refuses. Ligatures union the connected source provenance region, including nested substitutions and retained preceding/following glyphs sharing consumed clusters. Charged fixed-point scans propagate identical union intervals so output remains admissible under the same strict cluster partition rules. GSUB clears all metric fields; the caller resolves each final original GID's advance from the validated catalog before GPOS. Old component advances are never summed for ligatures.

All spans are bounded to4096 input glyphs. Input/scratch/output spans are disjoint. Scratch/output cannot overlap retained catalog or companion bytes. Output bytes and published count remain unchanged on refusal; scratch and cumulative work/output ledgers may be consumed. Reader limits and caller ledgers bound work; arithmetic overflow refuses.
